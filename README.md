Code by Emily E. Davis for Implicit Associative Memory and Aging - Functional Neuroimaging Project. 

Behavioural Analysis folder includes pre-processing scripts for e-prime output and behaviour x ROI analysis. 

Functional Analysis folder includes first and second level analysis SPM files, bash scripts for creating ITKSNAP workspaces for ASHS
and bash scripts for taking ASHS output to create subject-specific hippocampal masks.
